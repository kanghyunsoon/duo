# Day 14 exit interview

The same questions for every participant, asked after observation day 14. Please answer within 7 calendar days of the request ([protocol §27](README.md#27-pre-participant-clarifications-h-69)). Answers may be in English or Korean. [Protocol §15](README.md#15-exit-interview)

## Questions

1. Did you complete the 14 days? If not, on which day did you stop and why?
2. Will you keep using DUO in this repository?
3. Without DUO, which alternative would you go back to?
4. Was there a real moment when DUO did better than that alternative? Describe it.
5. How many useful findings did you have (as defined in the event log)?
6. How many noisy or false findings?
7. Was maintaining Truth and Decisions acceptable for what you got?
8. Was human confirmation of Decisions a safeguard or ceremony for you?
9. Did it matter that the review is deterministic and needs no model or account?
10. Did one Truth shared by agents actually help (only if you used more than one agent)?
11. Could you use DUO without the author's help?
12. Would you uninstall DUO now?
13. If you could remove one thing from DUO, what would it be?
14. If one thing makes you keep DUO, what is it?

**Final question (required):** Between DUO and the alternative you wrote down on day 0, which will you actually choose for this repository from now on?
