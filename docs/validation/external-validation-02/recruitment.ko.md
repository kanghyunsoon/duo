## 직접 요청(짧은 글)

> 안녕하세요 <이름>님, DUO라는 오픈소스 CLI를 만들고 있습니다. 사람이 확정한 설계 결정을 저장소에 기록하고, 코딩 에이전트가 만든 변경이 그 결정을 지키는지 검사합니다. 다만 이 도구를 기존 작업 흐름에 더할 가치가 있는지는 아직 모릅니다. 제 내부 테스트에서는 일반적인 lint 설정도 직접적인 위반은 똑같이 잡았고, DUO는 설정과 유지 작업이 더 듭니다.
>
> 이미 코딩 에이전트(Codex, Claude Code 등)를 쓰시는 분께 실제 저장소에서 써 봐 주시길 부탁드립니다. 처음 써 보는 10~15분 테스트가 있고, 원하시면 7~14일 동안 실제 작업에 쓰면서 도움이 된 일, 방해가 된 일, 든 시간을 적어 주시는 단계가 있습니다. 부정적인 결과도 똑같이 도움이 됩니다. source code나 개인정보는 수집하지 않고 telemetry도 없으며 언제든 그만두실 수 있습니다. 자세한 내용: <참가 안내 링크>. 관심 있으실까요? 관심 없으시면 답하지 않으셔도 되고 다시 연락드리지 않겠습니다.

## 커뮤니티 게시글

**오픈소스 코딩 에이전트 검사 도구를 작업 흐름에 더할 가치가 있는지 함께 확인해 주실 개발자를 찾습니다(부정적 결과 환영)**

DUO(`@duo-director/cli` 0.3.3, Apache-2.0)는 사람이 확정한 설계 결정을 저장소에 두고, 코딩 에이전트의 변경을 그 결정과 비교해 파일과 줄 근거로 보고합니다. LLM을 쓰지 않습니다.

모르는 것: 이 도구가 추가 단계만큼의 가치가 있는지입니다. 작은 fixture로 한 내부 테스트에서 일반적인 ESLint 설정과 짧은 dependency 검사가 직접적인 위반을 똑같이 막았고, DUO는 lint 규칙이 못 본 `require` 1건을 더 잡은 대신 오탐 1건이 있었습니다. 이전 벤치마크에서도 짧은 맞춤 script가 고정된 규칙에서는 DUO와 같은 결과를 냈습니다. 그래서 실제 개발자에게 직접 확인하려고 합니다.

- **1단계(10~15분)**: 설치, 에이전트 연결, 실제 변경 하나에 첫 review, 막힌 곳 기록
- **2단계(선택, 7~14일)**: 실제 작업에 사용, 도움이 되거나 방해가 되거나 시간이 든 일을 기록, 마지막에 20~30분 인터뷰
- **필요한 것**: 직접 유지하는 Git 저장소, 그 저장소에서 이미 쓰는 코딩 에이전트, Node.js 24.15 이상
- **개인정보**: source code, key, 개인 데이터 수집 없음, telemetry 없음, 결과는 S1, L1 같은 ID로만 공개
- **언제든 그만두실 수 있습니다.** 보상은 없고, 참가자가 쓴 시간을 결과와 함께 공개합니다.
- 참가할 수 없는 분: DUO 기여자, 설계·테스트 참여자

"가치가 있다"의 기준은 미리 정해 두었습니다: [protocol](README.md). 신청: <Discussion 링크>.
